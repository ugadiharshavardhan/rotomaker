# Brand fonts — Apoc Revelations (Blaze Type)

To use Apoc Revelations site-wide:

1. Add your licensed files here:
   - `ApocRevelations-Regular.woff2` (required)
   - `ApocRevelations-Bold.woff2` (optional)

2. Uncomment the `@font-face` block in `src/app/globals.css` (search "Apoc Revelations")
   and set `--font-display` back to `"Apoc Revelations", var(--font-bebas), …`.

Until then the site uses Bebas Neue so the console does not 404 missing fonts.
